# OGC Building Blocks Deep Dive 1

Sample register used to illustrate the OGC Building Blocks viewer in the first Building Blocks deep dive.


Contains a single sample building block showing metadata, description, JSON Schema,
semantic uplift (JSON-LD context), examples and transforms.


## Building Blocks

### `ogc.deepdive1.weatherObservation` — Weather Observation

**Type:** schema

A simple weather station observation of air temperature, with semantic uplift to SOSA.
